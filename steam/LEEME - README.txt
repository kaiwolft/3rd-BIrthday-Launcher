AGREGAR A STEAM / ADD TO STEAM — The 3rd Birthday (Dionixu's Launcher)
=======================================================================

ES
Windows
  1. En la carpeta donde instalaste el juego (la que contiene "launcher"), doble clic en AGREGAR_A_STEAM.bat.
     Si lo copias a otro sitio, te pedirá elegir The3rdBirthday.exe.
  2. Si Steam está abierto se cierra solo; ábrelo de nuevo cuando termine.
Linux / Steam Deck (modo escritorio)
  1. En la carpeta del juego ejecuta:  ./agregar_a_steam.sh   (o: python3 agregar_a_steam.py)
     El .bat de Windows NO funciona en Linux: este script hace lo mismo con Python 3.
  2. Si Steam está abierto se cierra solo; ábrelo de nuevo cuando termine.
  Con Steam en Flatpak el juego queda dentro de su sandbox: si no abre, usa el Steam nativo de tu distribución.
El juego aparece en tu Biblioteca con portada, fondo, logo e icono, para todos los usuarios de Steam del equipo.
Si ya estaba agregado, solo se actualiza (no pierdes el tiempo jugado). Se guarda una copia: shortcuts.vdf.antes_launchers.
Si el mando no responde: Steam > clic derecho al juego > Propiedades > Mando > "Desactivar Steam Input".
Si mueves la carpeta del juego, vuelve a ejecutarlo.

EN
Windows
  1. In the folder where you installed the game (the one containing "launcher"), double-click AGREGAR_A_STEAM.bat.
     If you copy it elsewhere it will ask you to pick The3rdBirthday.exe.
  2. If Steam is open it is closed automatically; start it again afterwards.
Linux / Steam Deck (desktop mode)
  1. In the game folder run:  ./agregar_a_steam.sh   (or: python3 agregar_a_steam.py)
     The Windows .bat does NOT work on Linux: this script does the same with Python 3.
  2. If Steam is open it is closed automatically; start it again afterwards.
  With Flatpak Steam the game runs inside its sandbox: if it does not start, use your distro's native Steam.
The game shows up in your Library with cover, background, logo and icon, for every Steam account on the computer.
If it was already added it is only updated (play time is kept). A backup is made: shortcuts.vdf.antes_launchers.
If the controller does not respond: Steam > right-click the game > Properties > Controller > "Disable Steam Input".
Run it again if you move the game folder.
